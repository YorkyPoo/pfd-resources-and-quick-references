# Poquoson Fire and Rescue Patient Care Protocols
## Procedures - Transcutaneous Pacing

### Overview
Management of unstable symptomatic bradycardia (HR <60 bpm).

### Indications
- Adult: Persistent symptomatic bradycardia (HR <60 bpm).
- Pediatric: Symptomatic bradycardia despite adequate ventilation, high-quality CPR, and appropriate pharmacological interventions ([Epinephrine](Epinephrine.md)/[Atropine](Atropine%20Sulfate.md)).

### Procedure
| # | Action / Intervention | EMR | EMT | A | I | P |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | Expose/clean chest, apply 4-lead ECG. | | | | • | • |
| 2 | Apply pads (anterior/posterior) and set to pacing mode. | | | | • | • |
| 3 | Set rate at 80 bpm. Initial current 50mA. | | | | • | • |
| 4 | Increase current (10mA/10s) until electrical capture achieved. | | | | • | • |
| 5 | Palpate femoral pulse to confirm mechanical capture. | | | | • | • |

### Pearls
*   Consider sedation/pain control prior to pacing; do not use both opiates and benzodiazepines due to risk of over-sedation.
*   Pacing can cause diaphragmatic spasm (hiccups).
*   Symptomatic bradycardia = HR <60 bpm + signs of poor perfusion (hypotension, chest pain, AMS, dyspnea, diaphoresis).
*   Atropine is often ineffective for high-degree AV blocks; pace early.
*   Pacing is rarely indicated for children <12; contact Medical Control at a pediatric specialty center.
