# Poquoson Fire and Rescue Patient Care Protocols
## Procedures - Endotracheal Intubation

### Overview
Endotracheal intubation is an advanced airway management technique for patients in respiratory failure, respiratory arrest, or those unable to maintain a patent airway.

### Criteria
- Respiratory failure or respiratory arrest
- Acute or impending airway obstruction
- Inability to maintain a patent airway
- Altered level of consciousness with ineffective or inadequate spontaneous respirations

### Procedure
| # | Action / Intervention | EMR | EMT | A | I | P |
| :--- | :--- | :---: | :---: | :---: | :---: | :--- |
| 1 | Pre-oxygenate: 100% O₂ via NRB or BVM for 3 mins. Monitor SpO₂. | | • | | • | |
| 2 | Position patient: Ear to sternal notch. Maintain in-line C-spine stabilization if trauma suspected. | | • | | • | |
| 3 | Prepare equipment: ETT (appropriate size + 1 size below), stylet/bougie, O₂, suction, laryngoscope, backup airway (SGA), BVM with EtCO₂. | | | | • | |
| 4 | Orally intubate (Patients ≥ 12 years). | | | | | • |
| 5 | Orally intubate (Patients < 12 years). | | | | | • |
| 6 | If unsuccessful, re-oxygenate with 100% O₂. After 2 failed attempts, manage via most experienced provider or alternative airway. | | | | | • |
| 7 | If unable to intubate and unable to oxygenate, proceed immediately to Surgical Airway. | | | | | • |
| 8 | Verify placement: Continuous box-waveform EtCO₂, bilateral lung sounds, absence of gastric sounds. | | | | • | |
| 9 | Secure tube: Tape or commercial holder. Document depth. | | | | • | |
| 10 | Administer analgesia/sedation as needed. | | | | | • |

### Pearls
*   Assume all intubations are potentially difficult.
*   Continuous box-waveform EtCO₂ monitoring is the accepted national standard. Loss of signal = immediate airway investigation.
*   Optimal de-nitrogenation and pre-oxygenation extend safe apnea time. Consider apneic oxygenation via nasal cannula (15 LPM) during procedure.
*   "Lead with suction": Clear secretions/vomit prior to laryngoscope advancement.
*   Avoid deep blade placement (vallecula is correct).
*   Intubation of pediatric patients (< 12 years) is a Paramedic "Red Dot" skill only.
