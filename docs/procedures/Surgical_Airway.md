# Poquoson Fire and Rescue Patient Care Protocols
## Procedures - Surgical Airway

### Overview
Last-resort airway management for patients who cannot be oxygenated or intubated by less invasive means.

### Indications
- Inability to oxygenate by less invasive means.
- **Surgical Cricothyrotomy:** ≥ 12 years old or > 35-40 kg.
- **Needle Cricothyrotomy:** < 12 years old or < 35-40 kg.

### Procedure
| # | Action / Intervention | EMR | EMT | A | I | P |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | Position supine, expose/clean neck, palpate cricothyroid membrane. | | | | | • |
| 2 | **Surgical Cric:** Vertical incision (2-3cm), horizontal incision through membrane, insert bougie, pass ETT (size 4.0-6.0). | | | | | • |
| 3 | **Needle Cric:** 14g catheter with syringe. Aspirate while advancing until pop/air aspiration. Advance catheter, remove needle. | | | | | • |
| 4 | Confirm/monitor placement with EtCO₂ and SpO₂. | | | | | • |
| 5 | Contact Medical Control and transport to closest ED. | MC | MC | MC | MC | MC |

### Pearls
*   Needle cricothyrotomy is unlikely to provide adequate ventilation. Prioritize oxygenation and transport.
*   Clearly document attempts at less invasive airway management prior to surgical airway.
*   Bleeding is common; utilize in-line suctioning.
*   If unable to secure airway, contact Medical Control and expedite transport.
