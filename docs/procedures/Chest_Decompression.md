# Poquoson Fire and Rescue Patient Care Protocols
## Procedures - Chest Decompression with Needle

### Overview
Needle decompression of the chest is a life-saving intervention for tension pneumothorax. It converts a tension pneumothorax (which causes mediastinal shift and cardiovascular collapse) to a simple pneumothorax.

### Indications
- **Unilateral or bilateral needle decompression:** Cardiac arrest, hypotension, clinical signs of shock, or poor perfusion AND absent or decreased breath sounds.
- **Bilateral needle decompression:** Cardiac arrest with evidence of significant blunt or penetrating thoracoabdominal trauma.

### Procedure
| # | Action / Intervention | EMR | EMT | A | I | P |
| :--- | :--- | :---: | :---: | :---: | :---: | :---: |
| 1 | Administer oxygen at 15 LPM (100% FiO2). | | | | • | |
| 2 | Locate 2nd intercostal space in the mid-clavicular line on the side of suspected pneumothorax (Alternate: 4th intercostal space, mid-axillary line). | | | | • | |
| 3 | Clean the site. | | | | • | |
| 4 | Attach a 10 mL syringe filled with 0.9% Sodium Chloride to a 14-gauge catheter needle (longest available). | | | | • | |
| 5 | Aspirate the syringe while advancing over the rib, perpendicular to the skin, into the pleural space until a pop is felt or air/blood/fluid is freely aspirated. **Do not advance needle further.** | | | | • | |
| 6 | Advance the catheter over the needle into the pleural space and remove the needle. | | | | • | |
| 7 | Reassess the patient, including vitals and respiratory effort/compliance. Consider repeating for continued/recurrent instability. | | | | • | |

### Pearls
*   Needle decompression has a failure rate of up to 50% due to catheter kinking, displacement, or lack of penetration. Use the longest 14-gauge catheter available.
*   If the initial attempt fails, consider a second attempt at the same site or an alternate (lateral) site on the same side.
*   Once needle decompression is performed, assume the patient has a pneumothorax. Use caution with positive pressure ventilation, as it may exacerbate the pneumothorax.
