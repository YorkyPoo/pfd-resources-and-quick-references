# Poquoson Fire and Rescue Patient Care Protocols
## Procedures - Capnography

### Overview
Continuous monitoring of end-tidal CO₂ (EtCO₂) is a mandatory procedure for any patient with an endotracheal tube (ETT) or supraglottic airway (SGA) in place. It is also a critical tool for assessing respiratory effort, ventilation, and perfusion in non-intubated patients.

### Indications
- Any patient requiring continuous monitoring of respiratory effort, ventilation, and/or perfusion.
- Mandatory for any patient with an ETT or SGA in place.

### Procedure
| # | Action / Intervention | EMR | EMT | A | I | P |
| :--- | :--- | :---: | :---: | :---: | :---: | :---: |
| 1 | **Adequate respiratory effort:** Apply EtCO₂ sampling nasal cannula to patient. | | • | | • | |
| 2 | **Inadequate respiratory effort / Apnea:** Attach in-line EtCO₂ sampling device to BVM, CPAP, or ventilator. | | • | | • | |
| 3 | **Continuous Monitoring:** Monitor reading and waveform continuously. | | • | | • | |
| 4 | **Advanced Airway (ETT/SGA):** Continuous monitoring is mandatory. Sudden drop or loss of EtCO₂ signal requires immediate verification of airway device placement and ventilation. | | • | | • | |
| 5 | **Cardiac Arrest:** If EtCO₂ < 10 mmHg or dropping during CPR, optimize compression rate, depth, and recoil. If ROSC is achieved, adjust ventilation to maintain EtCO₂ 35-45 mmHg. Do not hyperventilate. | | • | | • | |
| 6 | **TBI / Stroke:** Adjust ventilation to maintain EtCO₂ 35-45 mmHg. Do not hyperventilate. | | • | | • | |
| 7 | **Obstructive airway disease (Asthma/COPD):** Consider permissive hypercapnia. Prioritize oxygenation. | | • | | • | |

### Pearls
*   In general, an EtCO₂ < 20 mmHg suggests inadequate pulmonary perfusion (e.g., hypotension/pulmonary embolism) and/or severe metabolic derangement (e.g., diabetic ketoacidosis).
*   If using an in-line HEPA filter, attach the in-line EtCO₂ sampling device proximal to the HEPA filter (closer to the patient).
*   With high-quality CPR, EtCO₂ may consistently be measured in the normal range. Assess for ROSC if a sudden rise in EtCO₂ is noted (e.g., 12 mmHg to 35 mmHg).
*   Achieving normal EtCO₂ levels may not be possible for patients with chronic obstructive airway disease (asthma/COPD), particularly during acute exacerbations. Utilize bronchodilators to improve ventilation when necessary.
