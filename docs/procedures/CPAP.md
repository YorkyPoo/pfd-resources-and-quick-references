# Poquoson Fire and Rescue Patient Care Protocols
## Procedures - CPAP/BiPAP/PEEP

### Overview
Continuous Positive Airway Pressure (CPAP) provides positive pressure ventilation to assist patients with severe respiratory distress, reducing the need for intubation.

### Indications
- Any adult patient with respiratory distress due to pulmonary edema, infection, near-drowning, etc.
- Use with caution for patients experiencing respiratory distress due to asthma/COPD.
- Signs of respiratory distress: Accessory muscle use, SpO2 <94%, Respiratory rate >24, Inability to speak in complete sentences.

### Procedure
| # | Action / Intervention | EMR | EMT | A | I | P |
| :--- | :--- | :---: | :---: | :---: | :---: | :--- |
| 1 | Explain procedure and indications to the patient. | | • | | • | |
| 2 | Ensure adequate oxygen supply to the CPAP device. | | • | | • | |
| 3 | Set positive end-expiratory pressure (PEEP) to 5 cmH2O. | | • | | • | |
| 4 | Place mask over mouth/nose with oxygen flowing. Secure with straps, starting with lower straps. Minimize air leak. | | • | | • | |
| 5 | Reassess patient (SpO2, EtCO2, work of breathing). | | • | | • | |
| 6 | Consider titrating PEEP (5–15 cmH2O) as needed to improve ventilation. | | | | | • |

### Contraindications
- Apnea/agonal respirations
- Decreased level of consciousness (GCS ≤13)
- Pneumothorax
- Facial trauma, burns, or recent surgery
- Penetrating neck and/or chest trauma
- Active vomiting/severe nausea
- Hypotension (SBP <90 mmHg, MAP <65)
- Inability to tolerate tight-fitting mask

### Pearls
*   Positive pressure ventilation does not address the underlying cause of distress (e.g., bronchodilators for asthma, preload reduction for CHF).
*   Sudden hypotension may be due to increased intrathoracic pressure (breath stacking). Assess for pneumothorax; adjust PEEP, rate, and volume.
*   Avoid aspiration: Use only on conscious/alert patients. Remove immediately if patient vomits.
*   CPAP, BiPAP, and PEEP are "RED DOT" procedures at all EMS certification levels (refer to department-specific authorization/training policy).
