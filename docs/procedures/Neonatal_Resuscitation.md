# Poquoson Fire and Rescue Patient Care Protocols
## Procedures - Neonatal Resuscitation

### Overview
Resuscitation protocol for newborns/neonates (<28 days) with heart rate <100/min, apnea, or lack of pulse.

### Procedure
| # | Action / Intervention | EMR | EMT | A | I | P |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | Warm, dry, stimulate. Position airway (sniffing). Clear secretions ONLY if obstructed or thick meconium. | • | • | • | • | • |
| 2 | If apnea/gasping/HR <100: BVM with 21% O₂ for 30s, then 100% O₂. Rate: 40-60/min. | | • | | • | |
| 3 | Apply ECG and EtCO₂ monitoring. | | | | • | |
| 4 | If HR <60/min or pulseless: Begin compressions (3:1 ratio, 30 breaths/min). | | • | | • | |
| 5 | Obtain IV/IO access, administer [Epinephrine](Epinephrine.md) 0.01 mg/kg (0.1 mg/mL). Repeat q3-5 mins. | | | | | • |

### Pearls
*   Routine suctioning is no longer recommended.
*   Palpating a pulse on a neonate can be difficult; palpate at the umbilical stump or use a stethoscope on the chest.
*   Use a 3-way stopcock for precise fluid amounts. Do not use pressure bags.
*   Neonates are at high risk for hypoglycemia; assess glucose <40 mg/dL (newborn) or <60 mg/dL (neonate) and treat with D10W 5mL/kg.
