# Poquoson Fire and Rescue Patient Care Protocols
## Procedures - Intraosseous (IO) Access

### Overview
Intraosseous (IO) access is a rapid vascular access route for patients in extremis when standard IV access cannot be promptly obtained.

### Indications
- Any patient in extremis requiring immediate medication administration when IV access cannot be readily obtained (90 seconds or two failed attempts).

### Procedure
| # | Action / Intervention | EMR | EMT | A | I | P |
| :--- | :--- | :---: | :---: | :---: | :---: | :--- |
| 1 | Locate site: Proximal humerus (greater tubercle) or Proximal tibia (2-3 finger breadths below patella, 2 finger breadths medial). | | | • | | • |
| 2 | Clean site with alcohol/disinfectant. | | | • | | • |
| 3 | Insert needle perpendicular until tip touches bone (confirm 1 black line visible). | | | • | | • |
| 4 | Drill until loss of resistance is felt (medullary space entry). | | | • | | • |
| 5 | Remove driver, remove stylet (turn counter-clockwise), dispose in sharps. | | | • | | • |
| 6 | Secure needle, attach primed extension tubing. | | | • | | • |
| 7 | **Confirm/Flush:** Aspirate to confirm (if unconscious), flush with 10–20 mL 0.9% Sodium Chloride. | | | • | | • |
| 8 | **Pain Control (Conscious Patient):** Administer 2% [Lidocaine](Lidocaine.md) slow push (Adult: 1mg/kg max 40mg; Ped: 0.5mg/kg max 20mg). Dwell 1 min, flush. | | | | | • |

### Pearls
*   If two "pops" (losses of resistance) are felt, the needle likely passed through the bone.
*   IO flow rates: Proximal humerus (~80 mL/min), Tibia (~15 mL/min).
*   Any medication administered IV can be administered IO.
