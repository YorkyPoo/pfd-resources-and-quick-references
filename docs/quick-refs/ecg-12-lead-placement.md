# 12-Lead ECG Placement

## Limb leads — two colour standards, same anatomy

Place by **anatomy, not colour**. Many departments run both cable sets, so check the box you
are holding.

| Lead | Position | AHA / US colour | IEC / European colour |
|---|---|---|---|
| RA | Right arm / shoulder | **White** | Red |
| LA | Left arm / shoulder | **Black** | Yellow |
| LL | Left leg (lower abdomen/hip ok) | **Red** | Green |
| RL | Right leg (ground) | **Green** | Black |

Mnemonic for the US set: **"White on right, smoke over fire"** — black (smoke) on the left
arm, red (fire) on the left leg, green on the right leg.

**Limb leads can go on the torso** (below the clavicles, costal margins) if the limbs are
injured, amputated or the patient is moving — but say so on the transmission, because it
changes the tracing.

## Precordial leads — V1 to V6

| Lead | Landmark |
|---|---|
| **V1** | 4th intercostal space, **right** sternal border |
| **V2** | 4th intercostal space, **left** sternal border |
| **V4** first | 5th intercostal space, mid-clavicular line |
| **V3** | Halfway between V2 and V4 |
| **V5** | Anterior axillary line, same horizontal level as V4 |
| **V6** | Mid-axillary line, same level as V4 |

Place **V4 before V3**, then run V5/V6 across on that line — intercostal spaces are counted
from the **second** (the sternal angle) downward, which stops the common error of landing one
space too high.

## Contiguous groups: read the leads as territories

| Leads | Wall | Usual artery |
|---|---|---|
| **V1–V2** | Septal | LAD |
| **V3–V4** | Anterior | LAD |
| **V5–V6, I, aVL** | Lateral | LCx / diagonals |
| **II, III, aVF** | Inferior | RCA (~80%) or LCx |
| **aVR** | Cavity / septum baseline | — |

- **Two contiguous leads** with ST elevation are the pattern that matters — one lead alone is
  frequently normal variant.
- **Reciprocal depression** (e.g. ST↓ in I/aVL with inferior elevation) supports the
  diagnosis rather than arguing against it.
- **III + aVF without II** = lead-placement or positional effect, not a true inferior injury.
- **Isolated V1 elevation, or ST↓ V1–V3 with tall broad R waves** → think **posterior** MI;
  a three-lead posterior set (V7–V9) or right-sided leads settle it if your protocol allows.
- **Inferior STEMI + hypotension + clear lungs** → check **V4R** (right-sided) before giving
  preload-reducing drugs; right-ventricular infarction behaves badly to nitrates.

## Artefact checklist before you call it

Shivering and tremor, loose or dried electrodes, chest hair, pacemaker spikes, wandering
baseline from poor adhesion, and **leads placed one rib too high** (mimics anterior changes).
Repeat the tracing on the correct space before transmitting an equivocal one.
