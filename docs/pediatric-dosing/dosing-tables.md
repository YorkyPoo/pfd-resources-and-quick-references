# Pre-Calculated Pediatric Dosing Tables

All doses below are calculated from **Poquoson Fire & Rescue Patient Care Protocols** using the mg/kg values specified in each protocol. Select the patient's weight zone and read all doses directly — no math required.

## Defibrillation & Cardioversion

| Rhythm | Energy | Notes |
|--------|:------:|-------|
| **VF/Pulseless VT** (Defib) | 2 J/kg initial, then 4 J/kg | Biphasic defibrillator |
| **SVT** (Cardioversion) | 0.5-1 J/kg initial | Synchronized |
| **Unstable SVT** | 1-2 J/kg | Increase if ineffective |
| **Atrial Fib/Flutter** | 0.5-1 J/kg | Synchronized |
